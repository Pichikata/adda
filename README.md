# ADDA — Web inicial

Proyecto nuevo, independiente de SD Digital.

## Cómo verlo
Abrí `index.html` directamente en el navegador.

## Estructura
- `index.html` — contenido de la web
- `styles.css` — diseño responsive
- `script.js` — menú móvil
- `assets/adda-hero.png` — imagen de referencia de la portada

## Próximos pasos
1. Reemplazar textos/datos provisionales.
2. Cargar fotos reales del local.
3. Completar menú de empanadas y pizzas.
4. Buscar y agregar imágenes de los juegos.
5. Crear el catálogo completo de juegos.
6. Agregar ubicación, horarios y redes sociales.
